# Agents

Every agent working in this repository (builder, red team, reviewer, any tool that reads `AGENTS.md`) follows `CLAUDE.md` in this
folder: the founder's rules (no commits or pushes unless asked, red-team tests first from round one, PM-speak test descriptions), the PHP
rules, the stage rule, the changelog, the three test layers and how to run them, wp-env's ports and OmnaBase's e2e server.

The brief is in the OmnaBase repository (`docs/briefs/m13-wordpress-plugin.md`); this repository's decisions are in `DECISIONS.md`.
